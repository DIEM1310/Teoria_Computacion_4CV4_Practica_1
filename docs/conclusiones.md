# Conclusiones

Esta práctica me permitió trabajar con Git, con Docker y con autómatas finitos. Con Git y GitHub aprendí a avanzar por partes: confirmaciones pequeñas con mensajes que explican el cambio, una rama aparte y un Pull Request para fusionar el trabajo solo cuando está listo, de modo que el historial cuenta cómo se fue construyendo la práctica. Con Docker entendí que un contenedor es un entorno aislado y reproducible: al fijar las versiones de la imagen y de las bibliotecas, el mismo programa y las pruebas funcionaron igual en Python 3.11, 3.12 y 3.13. Con los autómatas en JFLAP vi que diseñar uno consiste en decidir qué debe recordar cada estado, y que probar cadenas válidas, inválidas y de frontera, como la cadena vacía, es lo que permite encontrar los errores del diseño. En conjunto, estas herramientas ayudan a que el trabajo sea ordenado, repetible y fácil de comprobar.
